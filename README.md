# D&D Toolkit — Frontend

Это подготовленная frontend-версия текущего D&D Toolkit.

## Структура

- `index.html` — разметка приложения
- `css/style.css` — стили
- `js/` — JavaScript, разделённый по назначению
- `api/api.js` — единая точка подключения будущего Backend

## Важно

Существующий функционал сохранён и JS-файлы подключаются в исходном порядке выполнения.
Сайт пока продолжает работать локально, как раньше.

Следующий этап:
1. вынести игровые данные из localStorage;
2. создать Backend;
3. подключить PostgreSQL;
4. добавить WebSocket для синхронизации карты, токенов, бросков и действий игроков;
5. добавить комнаты/кампании и роли Мастер/Игрок.
