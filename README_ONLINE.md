# D&D Toolkit — Online

В проект добавлены frontend + backend для кампаний и комнат.

Запуск: `backend/README.md`.

## Realtime sync

В этой версии добавлена WebSocket-синхронизация:
- состояние карты и её параметры;
- токены и их позиции;
- фигуры/слои;
- персонажи и монстры;
- инициатива;
- история кубиков;
- результат каждого броска виден всем участникам;
- рисунки и туман войны отправляются отдельным снимком после завершения операции.

Состояние комнаты хранится в PostgreSQL (`room_state`), поэтому после переподключения клиент получает последнее сохранённое состояние.
